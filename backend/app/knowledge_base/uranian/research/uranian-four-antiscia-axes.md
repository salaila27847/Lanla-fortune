## 1. การค้นพบหลัก: antiscia มี 4 แกน ไม่ใช่แกนเดียว

บทความระบุชัดว่านักโหราศาสตร์ยูเรเนียนใช้ antiscia **4 แกนสะท้อน** ไม่ใช่แค่แกนคลาสสิกแกนเดียว:

1. **Cancer/Capricorn (0°/180° ของแกนครีษมายัน)** — antiscia แบบดั้งเดิม (declination เท่ากัน)
2. **Aries/Libra (0°/180° ของแกนวิษุวัต)** — contra-antiscia (declination ตรงข้ามกัน) — เป็นเทคนิค
   คลาสสิกที่รู้จักกันทั่วไปอยู่แล้วในโหราศาสตร์ตะวันตก ไม่ใช่เฉพาะยูเรเนียน
3. **15° Taurus/Scorpio** — แกนที่ 3 ที่นักโหราศาสตร์ยูเรเนียน "เอา antiscia ไปไกลกว่านั้น" ตรวจสอบ
   ความสมมาตร/ศูนย์รังสีรอบแกนนี้ด้วย
4. **15° Leo/Aquarius** — แกนที่ 4 ในลักษณะเดียวกัน

จุดสำคัญ: ทั้ง 4 แกนนี้คือ**คู่ตรงข้ามทั้ง 4 คู่ของจุด "กางเขนแปดแฉก" (eight-armed cross)** เดียวกันที่
บทความเดียวกันนี้อธิบายไว้ (0° ราศีคาร์ดินัลทั้ง 4 + 15° ราศีคงที่ทั้ง 4 — จุดเดียวกับที่ยืนยันการแก้บั๊ก
mod-45 ใน `_dial90_orb()` ไปแล้ว ดู `uranian-dial-hierarchy.md`) พูดอีกแบบคือ: จุดกางเขนแปดแฉกมี 4
แกนตรงข้ามกัน (0°-180°, 45°-225°, 90°-270°, 135°-315°) และ antiscia ของยูเรเนียนก็คือการสะท้อนรอบ
แต่ละแกนใน 4 แกนนี้ทั้งหมด ไม่ใช่แค่แกนเดียว

### สูตรทั่วไป

การสะท้อน longitude `L` รอบแกนที่มุม `θ` (และ `θ+180`) คือ:

```
reflect_θ(L) = (2θ − L) mod 360
```

| แกน | θ | สูตร | ชื่อเรียก |
|---|---|---|---|
| Aries/Libra | 0° | `−L mod 360` | Contra-antiscia |
| Taurus/Scorpio | 45° | `(90 − L) mod 360` | (ไม่มีชื่อเฉพาะในบทความ) |
| Cancer/Capricorn | 90° | `(180 − L) mod 360` | Antiscia (แบบดั้งเดิม) |
| Leo/Aquarius | 135° | `(270 − L) mod 360` | (ไม่มีชื่อเฉพาะในบทความ) |

## 2. เทียบกับสิ่งที่ engine ทำอยู่ตอนนี้ — ช่องว่างจริง

`_antiscion()` ใน `engine.py` (ที่ implement ไปแล้วจากการวิจัย Niggemann) ทำแค่สูตรเดียว:

```python
def _antiscion(longitude: float) -> float:
    return (180.0 - longitude) % 360.0
```

นี่คือ `reflect_90` เท่านั้น — ตรงกับแกน **Cancer/Capricorn** แกนเดียวจาก 4 แกนที่บทความนี้ระบุ **ยังไม่มี
`reflect_0` (contra-antiscia), `reflect_45`, หรือ `reflect_135` เลย** เท่ากับว่า `_find_antiscia_contacts()`
ตรวจจับได้แค่ 1 ใน 4 ของความสัมพันธ์แบบสะท้อนที่ระบบนี้ใช้จริงตามแหล่งข้อมูลนี้

**หมายเหตุ:** ยังไม่ implement การขยายนี้ในรอบนี้ (ผู้ใช้เลือกให้บันทึกเป็น research ก่อน ยังไม่สั่งแก้โค้ด) —
ถ้าจะทำในอนาคต แนวทางที่ตรงไปตรงมาที่สุดคือสร้าง `_reflect(longitude, theta)` ทั่วไป (คล้ายกับที่ทำกับ
`_dial_fold_orb`) แล้วให้ `_antiscion()` เดิมเรียกมันด้วย `theta=90` และเพิ่มอีก 3 ฟังก์ชัน/พารามิเตอร์
สำหรับอีก 3 แกน จากนั้นขยาย `_find_antiscia_contacts()` ให้ตรวจทั้ง 4 แกนแทนที่จะมีแกนเดียว

## 3. การยืนยันไขว้อื่นๆ จากบทความเดียวกัน (บันทึกไว้เพื่อความสมบูรณ์)

- **กางเขนแปดแฉก (0° คาร์ดินัล + 15° ราศีคงที่ = ทวีคูณของ 45°)** — บทความอธิบายตรงกับสิ่งที่วิเคราะห์
  ไปแล้วในการแก้บั๊ก `_dial90_orb()` เป๊ะ (ยืนยันจากแหล่งข้อมูลที่สองที่ไม่ใช่ Niggemann/Rudolph) ตรวจสอบ
  เลขแล้วว่าจุดทั้ง 8 (0° Aries, 15° Taurus, 0° Cancer, 15° Leo, 0° Libra, 15° Scorpio, 0° Capricorn,
  15° Aquarius) ห่างกันเท่าๆ กันจริงที่ 45° ทุกช่วง
- **จาน 22.5° (16th harmonic)** — บทความยืนยันการมีอยู่ของจานนี้เช่นกัน ตรงกับ `_dial225_orb()`/
  `find_fine_timing_hits()` ที่ implement ไปแล้ว
- **ตัวอย่างคำนวณที่ตรวจสอบแล้ว** — บทความยกตัวอย่าง Mars 13°Gemini, Jupiter 19°Sagittarius, Venus
  25°Taurus, Saturn 7°Capricorn เป็น picture แบบ A+B−C=D **ตรวจสอบด้วยเลขจริงแล้วถูกต้อง**:
  Mars(73°)+Jupiter(259°)−Venus(55°) = 277° = Saturn พอดี — เหมาะเป็น test fixture ที่มาจากแหล่งข้อมูล
  ภายนอกจริง (ไม่ใช่ synthetic) ถ้าต้องการเพิ่มในอนาคต
- **คำหลักดาวเสริมทั้ง 8** — ไม่ขัดแย้งกับ `points.yaml` (เป็นแหล่งที่ 3 ที่ยืนยันตรงกันแล้ว ต่อจาก
  Niggemann และ witte_pictures.yaml เดิม)
- **ระบบเรือน 6 ระบบ** (Meridian, Earth, Ascendant, Sun, Moon, Node horoscope) — บทความอธิบาย
  ละเอียดกว่าที่มีอยู่ใน `uranian-basics-ch1-5.md`/`uranian-delineation-axes.md` ปัจจุบัน (ที่พูดถึงแค่
  "equal-house จาก M" กว้างๆ) — เป็นข้อมูลที่อาจช่วยเติมช่องว่าง "ไม่มี house_meanings" ที่ README ระบุไว้
  ใน "ยังไม่ได้ทำ" แต่**ต้องออกแบบการคำนวณ house cusp จริงก่อน** (ยังไม่ implement ในโค้ดเลย) จึงยังไม่
  actionable ทันที — บันทึกไว้เป็นข้อมูลอ้างอิงสำหรับตอนที่จะเริ่มงานนั้น
- **ประวัติ Witte (1878–1943)/Sieggrün (1877–1951)/Kepler Circle** — สอดคล้องกับที่ Niggemann เขียน
  ไว้เรื่องจุดเริ่มต้นจากความไม่พอใจวิธีพยากรณ์สงครามยุคสมัยนั้น ไม่มีข้อขัดแย้ง
