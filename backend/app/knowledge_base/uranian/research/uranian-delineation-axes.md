# การตีความตามแกน (Delineation) — M / A / Sun / Moon / Node

> สรุป/ถอดความจากหนังสือ *The Language of Uranian Astrology* โดย Roger A. Jacobson บทที่ IX (Delineation)
> เอกสารนี้เป็นการถอดความเชิงโครงสร้างเพื่อใช้งานภายในโปรเจค ไม่ใช่คำแปลตรงตัวจากต้นฉบับ

---

## 1. หลักการของบทนี้

หนังสือเน้นว่าการตีความ (delineation) คือขั้นตอนสุดท้ายที่นำทุกอย่างที่เรียนมารวมกัน — ความหมายของดาว, การคำนวณดวง, Aspect, Planetary Picture, และหน้าปัด 360°/90° — เข้ามาผสานเป็นคำอธิบายดวงชะตาที่สมบูรณ์

สัญกรณ์ผลรวม (เช่น "M + Sun") ในบทนี้ใช้ได้ 2 ความหมาย:
1. เป็นเพียงวิธีสื่อว่าอิทธิพลสองอย่างทำงานร่วมกัน (ผ่าน aspect ระหว่างกัน หรือผ่านการที่ดาวดวงหนึ่งตกอยู่ในเรือนของอีกจุดหนึ่ง)
2. เป็น planetary picture เต็มรูปแบบ (Type I หรือ Type II) ตามที่อธิบายไว้ในเอกสารตรรกะการคำนวณ

**สำหรับระบบ engine:** แกนที่สำคัญที่สุด 5 แกนคือ **M, M/Sun, M/A, A, A/Sun** — ควรให้ engine คำนวณ combination ของแกนเหล่านี้เป็นลำดับแรกก่อนขยายไปแกนอื่น (ตามที่ระบุไว้ในขั้นตอน Delineation Procedure ของเอกสาร Phase 1)

---

## 2. M-Axis (Midheaven) — ตัวตนและอาชีพในโลกภายนอก

M คือแกนที่สะท้อน "ตัวตนสาธารณะ" อาชีพ และภาพลักษณ์ต่อโลกภายนอก ความหมายของแต่ละคู่ดาวบนแกนนี้จะเน้นไปทาง **มิติส่วนตัว/ภายในของประเด็นนั้นๆ**

| คู่ดาว | ธีมความหมาย (ถอดความ) |
|---|---|
| M + Aries | ตัวตนของผู้เจ้าของดวงในโลกภายนอก บทบาททางอาชีพ |
| M + Sun | อัตตาส่วนตัว ร่างกายและจิตวิญญาณ การแสดงออกของ "ตัวฉัน" |
| M + A | ปฏิสัมพันธ์ระหว่างตนเองกับสิ่งแวดล้อม |
| M + Moon | อารมณ์และความรู้สึกที่มีต่อตนเอง |
| M + Node | ความผูกพันส่วนตัว เครือข่ายทางอาชีพ วงสังคมส่วนตัว |
| M + Mercury | ความคิดส่วนตัว การครุ่นคิด บทสนทนากับตัวเอง |
| M + Venus | รสนิยมและความชอบส่วนตัว ความสามารถในการรัก ความสุขส่วนตัว |
| M + Mars | การผจญภัยส่วนตัว การกระทำที่ขับเคลื่อนจากภายใน ข้อพิพาทในหน้าที่การงาน |
| M + Jupiter | โชคดีส่วนตัว ความสุขภายใน |
| M + Saturn | ภาระและความรับผิดชอบส่วนตัว ความมุ่งมั่นภายใน หรือความหดหู่ หน้าที่ในอาชีพ |
| M + Uranus | ความตึงเครียดภายใน ความประหลาดใจ การเบี่ยงเบนจากขนบส่วนตัว |
| M + Neptune | จินตนาการและจุดอ่อนส่วนตัว ความไม่มั่นคงในใจ ทัศนคติต่ออนาคต |
| M + Pluto | พัฒนาการส่วนตัว การเปลี่ยนแปลงภายใน ความก้าวหน้าในอาชีพ |
| M + Cupido | ความผูกพันกับครอบครัว พ่อแม่ของตนเอง ความสมดุลและรสนิยมทางศิลปะ |
| M + Hades | ความทุกข์ใจหรือความเดือดร้อนส่วนตัว ความลับส่วนตัว |
| M + Zeus | เป้าหมายส่วนตัวและอาชีพ ความสามารถเชิงสร้างสรรค์ ความปรารถนาในความสำเร็จ |
| M + Kronos | ความสามารถส่วนตัว ความเป็นอิสระ การเป็นผู้เชี่ยวชาญ |
| M + Apollon | ขอบเขตประสบการณ์ชีวิต ความสำเร็จส่วนตัว การค้าขาย/วิทยาศาสตร์ โอกาสในอาชีพ |
| M + Admetos | ความมั่นคงภายใน การเฉื่อยชาหรือไม่แยแส ความดื้อรั้นส่วนตัว |
| M + Vulcanus | พลังภายใน อำนาจส่วนตัว |
| M + Poseidon | ประกายศักดิ์สิทธิ์ภายใน จิตวิญญาณของตนเอง |

**ตัวอย่างการใช้จากหนังสือ (คดี Judy Garland, ถอดความ):** หนังสือสาธิตว่าเมื่อ Jupiter อยู่ตรง midpoint ของ M/Kronos จะเน้นย้ำความสำเร็จและความมั่นคงทางการเงิน จากนั้นดูตำแหน่งเรือนของ Jupiter เพิ่มเติมเพื่อขยายรายละเอียด (เช่น เรือนที่ 4 ของ M บ่งบอกถึงบ้านที่หรูหรา) และยังแสดงว่าปัจจัยอื่นบนแกนเดียวกัน (เช่น Moon/Venus, Neptune/Vulcanus) ช่วยเติมมิติความรู้สึกที่ซับซ้อนขึ้น เช่น ความไม่มั่นคงภายในที่ซ่อนอยู่เบื้องหลังความสำเร็จภายนอก — สาธิตให้เห็นว่าการตีความ picture หนึ่งอันไม่เพียงพอ ต้องนำหลายปัจจัยบนแกนเดียวกันมาประกอบกันเสมอ

## 3. A-Axis (Ascendant) — ความสัมพันธ์กับสิ่งแวดล้อมและผู้อื่น

A คือแกนที่สะท้อน "โลกภายนอก" ความสัมพันธ์กับผู้อื่น และสิ่งแวดล้อมรอบตัว — ตรงข้ามกับ M ที่เน้นมิติภายใน

| คู่ดาว | ธีมความหมาย (ถอดความ) |
|---|---|
| A + Aries | ความสัมพันธ์กับโลกภายนอก สภาพแวดล้อมกลางแจ้ง |
| A + Sun | การมีตัวตนทางกายภาพในสถานที่นั้น การอยู่ต่อหน้าผู้อื่น |
| A + Moon | ความสัมพันธ์กับผู้หญิง ความสัมพันธ์เชิงอารมณ์ ความสัมพันธ์กับสาธารณชน |
| A + Node | การเชื่อมโยงกับสิ่งแวดล้อม วงสังคมในสถานที่นั้น การรักษาความสัมพันธ์ใกล้ชิด เขตแดน |
| A + Mercury | การสนทนา การติดต่อสื่อสาร ความคิดของผู้อื่น |
| A + Venus | ความสัมพันธ์เชิงรัก มิตรภาพที่น่ารื่นรมย์ ความงามในสิ่งแวดล้อม |
| A + Mars | กิจกรรมร่วมกับผู้อื่น การโต้เถียง |
| A + Jupiter | แหล่งทรัพย์สินในสิ่งแวดล้อม ความสุขผ่านผู้อื่น การได้รับความช่วยเหลือ |
| A + Saturn | ภาระผูกพันต่อผู้อื่น ความห่างเหิน การแยกจาก ความโดดเดี่ยว |
| A + Uranus | การพบเจอแบบฉับพลัน ผู้คนรอบข้างที่อยู่ในสภาวะตื่นเต้นหรือกระวนกระวาย สิ่งเร้าจากภายนอก |
| A + Neptune | การถูกหลอกลวง ความลังเลหรือไม่รับผิดชอบของผู้อื่น |
| A + Pluto | การย้ายที่อยู่ การเปลี่ยนแปลงของสิ่งแวดล้อม ผู้อื่นเปลี่ยนทัศนคติที่มีต่อเรา จุดเปลี่ยนในความสัมพันธ์ |
| A + Cupido | ความสัมพันธ์ในครอบครัว การอยู่ร่วมกับศิลปิน บ้านเกิด ญาติพี่น้อง ที่อยู่อาศัย |
| A + Hades | ด้านมืดของชีวิตในพื้นที่นั้น ความสัมพันธ์กับผู้ด้อยโอกาสทางสังคม/เศรษฐกิจ ผู้อื่นประสบความยากลำบาก |
| A + Zeus | เหตุการณ์ที่เกิดใกล้ตัว การสร้างสรรค์ร่วมกับผู้อื่น ผู้อื่นเป็นผู้นำหรือให้ทิศทาง |
| A + Kronos | คนทำงาน ลูกจ้าง เจ้าหน้าที่ ความสัมพันธ์กับผู้มีอำนาจ หน่วยงานรัฐในพื้นที่นั้น |
| A + Apollon | ความสัมพันธ์กับผู้คนจำนวนมาก โอกาส สถานที่ห่างไกล ต่างแดน |
| A + Admetos | ความมั่นคง รากฐาน ผู้อื่นถอยห่างหรือเป็นรอง ชนบท |
| A + Vulcanus | อิทธิพลที่แข็งแกร่งของผู้อื่นที่มีต่อชีวิตเรา |
| A + Poseidon | ความสัมพันธ์กับผู้มีแนวคิดคล้ายกัน ผู้อื่นนำพาความกระจ่างมาสู่สถานการณ์ สิ่งแวดล้อมเชิงจิตวิญญาณ |

## 4. Sun-Axis — ร่างกาย พลังชีวิต และความเป็นชาย

| คู่ดาว | ธีมความหมาย (ถอดความ) |
|---|---|
| Sun + Mars | ความเป็นชาย ชายผู้กระตือรือร้น ทหาร สามี |
| Sun + Jupiter | เงินทอง ความสุขทางกาย สิ่งของมีค่า |
| Sun + Saturn | ข้อจำกัดทางร่างกาย ความประหยัด การแยกทางกาย ชายชรา วินัยประจำวัน |
| Sun + Uranus | ความกระสับกระส่ายทางกาย ความตึงเครียด ความตื่นเต้นรายวัน (เกี่ยวโยงกับหัวใจ) |
| Sun + Neptune | พลังชีวิตต่ำ ร่างกายอ่อนแอ ไวต่อภูมิแพ้ ความเหนื่อยล้าที่อธิบายไม่ได้ การบิน |
| Sun + Pluto | พัฒนาการทางกาย การดูดซึมอาหาร ศักยภาพในการฟื้นฟู ปีแห่งการเติบโต (วัยเด็ก) |
| Sun + Cupido | สมาชิกชายในครอบครัว ศิลปิน ชายที่แต่งงานแล้ว |
| Sun + Hades | ร่างกายเจ็บป่วย ความพิการทางกาย โชคร้ายที่ตามมา ผู้แบกความลับ |
| Sun + Zeus | การยืนหยัดเพื่อตนเอง เจตจำนงในการสร้างสรรค์ ชายผู้มีเป้าหมาย วันแห่งความสำเร็จ บิดา ความเป็นผู้นำ |
| Sun + Aries | การดำรงอยู่ทางกายภาพบนโลกโดยทั่วไป |
| Sun + Moon | ชายและหญิง การแต่งงาน พ่อแม่ มิตรภาพ |
| Sun + Node | ความเชื่อมโยงทางกาย การจับแขนเดินคู่กัน ความสัมพันธ์กับผู้ชาย |
| Sun + Mercury | จิตสำนึกตื่นตัว ร่างกายที่เคลื่อนไหว |
| Sun + Venus | ความงามทางกาย วันที่น่ารื่นรมย์ เสน่ห์ส่วนตัว ชายรูปงาม |
| Sun + Kronos | ความเพียรพยายาม อสังหาริมทรัพย์ ความมั่นคง |
| Sun + Vulcanus | พลังทางกาย พลังของอัตตา ประสบการณ์เข้มข้นในแต่ละวัน |
| Sun + Poseidon | กายทิพย์ ชายผู้มีจิตวิญญาณสูง แสงสว่างทางกาย |

## 5. Moon-Axis — อารมณ์และความเป็นหญิง

| คู่ดาว | ธีมความหมาย (ถอดความ) |
|---|---|
| Moon + Node | สายใยทางอารมณ์ ความผูกพันด้านความรู้สึก |
| Moon + Aries | ผู้คนโดยทั่วไป ชีวิตสาธารณะ |
| Moon + Mercury | จิตใต้สำนึก ความคิดผสานกับความรู้สึก |
| Moon + Venus | ความเป็นหญิง หญิงงาม ความรู้สึกรัก การตั้งครรภ์ ความเป็นแม่ |
| Moon + Mars | กิจกรรมทางความคิด การกระทำที่ขับเคลื่อนด้วยอารมณ์ ชั่วโมงทำงาน ภรรยา |
| Moon + Jupiter | ความเชื่อ หญิงร่าเริง อารมณ์ดี |
| Moon + Saturn | การยับยั้งชั่งใจ การควบคุมตนเอง หญิงสูงวัย ช่วงเวลาโดดเดี่ยว ความหดหู่ การแยกจากผู้หญิง |
| Moon + Uranus | การตื่นขึ้น ความตกใจ หญิงที่กระวนกระวาย ความตื่นตัว |
| Moon + Neptune | การหลับใหล การฝัน หญิงที่หลอกลวงหรือถูกหลอกลวง ความสับสนทางอารมณ์ |
| Moon + Pluto | แนวโน้มทางอารมณ์สุดขั้ว การเปลี่ยนแปลงที่มาไวไปไว |
| Moon + Cupido | ภรรยา เวลาว่าง ชีวิตสังคม |
| Moon + Hades | การสละ/ลาออก ความรู้สึกไม่สุขใจ ความทุกข์ทางอารมณ์ |
| Moon + Kronos | จิตใจเชิงสร้างสรรค์ วินัย แรงจูงใจในการบรรลุเป้าหมาย |
| Moon + Zeus | คุณสมบัติทางอารมณ์อันสูงส่ง ผู้นำหญิง มารดา ข้าราชการ |
| Moon + Apollon | ประสบการณ์ทางอารมณ์ ฝูงชน อิสรภาพ |
| Moon + Admetos | ความสงบ การไตร่ตรอง พื้นที่ปิด |
| Moon + Vulcanus | ความเข้มข้นทางอารมณ์ สติที่เต็มเปี่ยม อิทธิพลของผู้หญิง |
| Moon + Poseidon | ความเห็นอกเห็นใจ การตอบสนองต่อสิ่งทางจิตวิญญาณ ร่างทรง |

**หมายเหตุพิเศษเรื่อง Moon (ถอดความจากหนังสือ):** ผู้เขียนอธิบายว่าดวงจันทร์มีความซับซ้อนสูง ควรตีความในหลายระดับพร้อมกัน ได้แก่ (1) ผู้หญิง (2) ผู้คนทั่วไป/มวลชน (3) อารมณ์ (4) กระบวนการทางความคิด (5) ชั่วโมง (6) เดือน — ตัวอย่างเช่น Moon/Mars ตีความต่างกันในแต่ละระดับ: ระดับ (1) = หญิงที่กระตือรือร้น, ระดับ (2) = ประชากรผู้ใช้แรงงาน, ระดับ (3) = ความก้าวร้าวหรือกระตือรือร้นที่จะลงมือทำ, ระดับ (4) = ความคิดที่เฉียบคม, ระดับ (5) = ชั่วโมงทำงานหนัก, ระดับ (6) = เดือนที่เร่งรีบวุ่นวาย — **นี่คือหลักการสำคัญที่ engine ควรนำไปใช้: ความหมายของ Moon-picture ควรมีหลายชั้นความหมายให้ synthesis layer เลือกใช้ตามบริบทของคำถาม** (เช่น ถามเรื่องคน vs ถามเรื่องช่วงเวลา)

## 6. Node-Axis — ความสัมพันธ์และเครือข่าย

| คู่ดาว | ธีมความหมาย (ถอดความ) |
|---|---|
| Node + Aries | การเชื่อมโยงกับโลกภายนอก วัฒนธรรมย่อย ความสัมพันธ์แบบไม่เป็นส่วนตัว |
| Node + Mercury | การติดต่อทางจดหมาย กระแสความคิด สัญญา |
| Node + Venus | สายสัมพันธ์แห่งความรัก ความผูกพันใกล้ชิด |
| Node + Mars | พันธมิตรในการทำงาน เรื่องเพศ |
| Node + Jupiter | ความเชื่อมโยงด้านการเงิน ข้อตกลงทางการเงิน |
| Node + Saturn | ความสัมพันธ์กับผู้สูงวัย การตัดขาดความสัมพันธ์ หุ้นส่วนที่มีความรับผิดชอบ |
| Node + Uranus | ความสัมพันธ์ที่เกิดขึ้นฉับพลัน เหตุการณ์พลิกผันในวงสังคม สายไฟฟ้า |
| Node + Neptune | การล่มสลายของความสัมพันธ์ การเชื่อมโยงกับคนที่ไว้ใจไม่ได้ |
| Node + Pluto | สายสัมพันธ์ใหม่ที่เกิดขึ้น การเปลี่ยนแปลงผ่านความสัมพันธ์ |
| Node + Cupido | สายใยครอบครัว กลุ่มศิลปะ การรวมกลุ่ม/องค์กร |
| Node + Hades | ความสัมพันธ์ลับ การคบหาที่ไม่น่าพึงใจ เชื่อมโยงกับอดีตอันไกลโพ้น |
| Node + Zeus | การเลือก การตัดสินใจร่วม การรวมตัวเพื่อเป้าหมายร่วมกัน |
| Node + Kronos | ความสัมพันธ์กับหน่วยงานรัฐ ราชการ ความสัมพันธ์ทางการทูต การเชื่อมโยงกับผู้มีอำนาจ |
| Node + Apollon | ความสัมพันธ์ในแวดวงวิทยาศาสตร์/การค้า การรวมกลุ่มจำนวนมาก อิสระในการสมาคม |
| Node + Admetos | ความสัมพันธ์กับคนกลุ่มเล็กที่คัดสรร ความผูกพันที่ยั่งยืน |
| Node + Vulcanus | ความเชื่อมโยงกับผู้มีอำนาจ ผลกระทบของความสัมพันธ์ที่มีต่อชีวิต |
| Node + Poseidon | ความสัมพันธ์เชิงศาสนา วงคนที่มีแนวคิดคล้ายกัน สายใยทางจิตวิญญาณ |

## 7. ความหมายของดาวแต่ละดวงเมื่ออยู่ในเรือน (ทั่วไป, ไม่ผูกกับแกนใดแกนหนึ่ง)

ส่วนนี้เป็นหลักการทั่วไปว่า "เรือนที่ดาวดวงหนึ่งสถิตอยู่" จะมีธรรมชาติแบบใด — ใช้ประกอบกับทุกแกนด้านบน

| ดาว | ธรรมชาติของเรือนที่ดาวนั้นสถิต (ถอดความ) |
|---|---|
| Sun | เรื่องที่ดำเนินไปด้วยพลังชีวิต ความกระตือรือร้น ความมั่นใจในตนเอง |
| Moon | เรื่องที่ผันผวนตามอารมณ์ เกี่ยวข้องกับมนุษย์ มีจังหวะการเปลี่ยนแปลง |
| Mercury | เรื่องที่เป็นประเด็นทางความคิดและบทสนทนา ต้องการความกระจ่างและความเฉียบไว |
| Venus | เรื่องที่มักนำมาซึ่งความเพลิดเพลินหรือความงาม เรื่องความรักอาจเกี่ยวโยงกับเรือนนี้ |
| Mars | เรื่องที่กระตุ้นให้เกิดการกระทำ อาจนำมาซึ่งความหงุดหงิดหรือข้อโต้แย้ง |
| Jupiter | เรื่องที่มีแนวโน้มเจริญรุ่งเรือง แหล่งรายได้และความสุขอาจมาจากเรือนนี้ |
| Saturn | เรื่องที่ต้องการโครงสร้าง วินัย กำหนดการ และความอดทนรอคอย |
| Uranus | เรื่องที่พลิกผันฉับพลัน ต้องการความหยั่งรู้และความคิดสร้างสรรค์ อาจเกี่ยวโยงกับเทคโนโลยี |
| Neptune | เรื่องที่เสื่อมสลายง่ายหากปล่อยละเลย เต็มไปด้วยภาพลวงตา แต่ก็เป็นแหล่งของแรงบันดาลใจทางจิตวิญญาณได้เช่นกัน |
| Pluto | เรื่องที่อยู่ในสภาวะเปลี่ยนผ่าน จุดศูนย์กลางของวิกฤตหรือการเปลี่ยนแปลงใหญ่ในชีวิต |
| Cupido | เรื่องที่เกี่ยวกับชีวิตครอบครัว งานศิลปะ การแต่งงาน และชุมชน/สังคม |
| Hades | เรื่องที่อาจผิดพลาดได้หากไม่แก้ไข อาจเกี่ยวโยงกับอดีตอันไกลโพ้นหรือหน้าที่ที่ถูกเรียกร้อง |
| Zeus | เรื่องที่เจ้าของดวงทุ่มเทพลังและความมุ่งมั่นเพื่อบรรลุเป้าหมาย แสดงออกถึงความเป็นผู้นำ |
| Kronos | เรื่องที่เน้นความเป็นเลิศ อาจเกี่ยวโยงกับภาครัฐหรืออิทธิพลของผู้บังคับบัญชา |
| Apollon | เรื่องที่มักส่งผลดีต่อความสำเร็จ เปิดมุมมองและขอบฟ้าที่กว้างขึ้น โอกาสมาเยือน |
| Admetos | เรื่องที่เปลี่ยนแปลงช้ามาก เป็นรากฐานที่มั่นคง แต่บางครั้งอาจรู้สึกติดขัดหรือจนมุม |
| Vulcanus | เรื่องที่ดำเนินไปอย่างเข้มข้น ต้องแสดงพลังของตนเองหรือรับแรงกดดันจากผู้อื่น |
| Poseidon | เรื่องที่นำไปสู่ความเข้าใจภายใน การแสวงหาความจริงและความกระจ่าง |
