# พื้นฐานทั่วไปของระบบยูเรเนียน — บทที่ I-V (สรุปย่อ)

> สรุป/ถอดความจากหนังสือ *The Language of Uranian Astrology* โดย Roger A. Jacobson บทที่ I-V
> เอกสารนี้เป็น "reference สั้น" ตามแผน Phase 4 — เน้นแนวคิดหลักที่จำเป็นต่อระบบ ไม่ใช่คำแปลเต็มบท

## บทที่ 1: จุดส่วนบุคคล (The Personal Points)

### แนวคิดพื้นฐาน
- โหราศาสตร์ยูเรเนียนใช้ระบบ **geocentric** (โลกเป็นศูนย์กลาง) วัดตำแหน่งดาวบน **เส้นสุริยวิถี (ecliptic)**
- ตำแหน่งดาวบอกได้ 2 แบบ: **zodiacal notation** (เช่น "5 Gemini 18") และ **whole-circle notation** (0-360°, เช่น "65°18'") — ระบบยูเรเนียนใช้ whole-circle เป็นหลักเพราะสะดวกต่อการคำนวณ midpoint
- **จุดคาร์ดินัล (Cardinal Points)** คือ 0° ของราศี Aries, Cancer, Libra, Capricorn — ในระบบยูเรเนียนมักถือว่าทั้งสี่จุดนี้ "เทียบเท่ากันได้" และเรียกรวมว่า Aries Point

### 6 จุดส่วนบุคคล (Personal Points)
ระบบยูเรเนียนใช้ปัจจัย 22 ตัว ประกอบด้วย 6 "จุดส่วนบุคคล" + 16 "ดาว" โดยจุดส่วนบุคคล ได้แก่:

| จุด | ความหมายแกนหลัก |
|---|---|
| **Aries Point** | โลกภายนอกโดยทั่วไป ความสัมพันธ์แบบไม่เจาะจงตัวบุคคล |
| **M (Midheaven/Meridian)** | ตัวตนภายใน อัตตา ตัวฉัน — จุดสำคัญที่สุดในดวงชะตา ผูกกับ "นาที" ในทางพยากรณ์ |
| **A (Ascendant)** | สิ่งแวดล้อมโดยรอบ ความสัมพันธ์กับผู้อื่น "เขา/เธอ" |
| **Sun** | การมีตัวตนทางกาย ผูกกับ "วัน" ในทางพยากรณ์ |
| **Moon** | อารมณ์และจิตใต้สำนึก ผูกกับ "ชั่วโมง" ในทางพยากรณ์ |
| **Node** | สายสัมพันธ์และการเชื่อมโยง (จุดเชื่อมระหว่าง A กับ Aries Point) |

**หลักการสำคัญ:** M กับ A ขึ้นอยู่กับทั้งเวลาและสถานที่เกิด (ลองจิจูด+ละติจูด) — คนที่เกิดเวลาเดียวกันแต่ต่างสถานที่จะมีค่า A ต่างกันมาก แม้ M อาจใกล้เคียงกัน (ถ้าอยู่บนเส้นเมริเดียนใกล้กัน) นี่คือกลไกที่ทำให้ดวงชะตาแต่ละคนมีเอกลักษณ์เฉพาะตัว แม้ตำแหน่งดาวเคราะห์จะเหมือนกัน

**แนวคิดเรื่อง Rectification:** กระบวนการหาเวลาเกิดที่แม่นยำ (เมื่อไม่ทราบเวลาเกิดชัดเจน) โดยย้อนกลับจากเหตุการณ์สำคัญในชีวิตมาเทียบกับค่า M/A ที่เป็นไปได้

## บทที่ 2: ดาวเคราะห์ (The Planets) — ระบบคำหลัก (Keywords)

### แนวคิด "โหราศาสตร์คือภาษา"
หนังสือเปรียบดวงชะตาเหมือนภาษาต่างประเทศ: ดาว 22 ดวงคือ "คำศัพท์" และรูปแบบทางเรขาคณิต (aspect, midpoint) คือ "ไวยากรณ์" นักโหราศาสตร์ต้อง "แปล" การจัดเรียงดาวให้เป็นประโยคที่มีความหมาย — ความหมายของคำหลักแต่ละคำไม่ได้ขัดแย้งกันเอง แต่เป็นจริงพร้อมกันหมด ทักษะอยู่ที่การเลือกคำหลักที่เหมาะกับบริบทของ configuration นั้นๆ

ระบบยูเรเนียนเพิ่มดาวสมมติ (transneptunian planets) 8 ดวง ที่ค้นพบทางโหราศาสตร์โดย Alfred Witte และ Friedrich Sieggrün — ดาวเหล่านี้ขยาย "คลังคำศัพท์" ให้ระบบมีความละเอียดมากขึ้น

### โครงสร้างคำหลักของดาวแต่ละดวง (Principle / Function / Expression / Manifestation)
หนังสือจัดหมวดคำหลักของดาวแต่ละดวงเป็น 4 มิติ:
- **Principle** หลักการพื้นฐานของดาว
- **Function** บทบาทเชิงหน้าที่
- **Expression** การแสดงออก
- **Manifestation** รูปธรรมที่ปรากฏในชีวิตจริง

ตัวอย่างสรุปแบบย่อ (ถอดความ ไม่ใช่คำแปลตรงตัว):

| ดาว | แก่นความหมาย |
|---|---|
| Sun | พลังชีวิต การมีตัวตน การขับเคลื่อนสู่ความสำเร็จส่วนตัว เชื่อมโยงกับร่างกายชาย บิดา |
| Moon | การตอบสนองทางอารมณ์ สัญชาตญาณ การเลี้ยงดู เชื่อมโยงกับร่างกายหญิง มวลชน |
| Mercury | สติปัญญา การสื่อสาร การปรับตัว เชื่อมโยงกับงานเขียน การเดินทาง เยาวชน |
| Venus | การประเมินคุณค่าทางอารมณ์ ความรัก ความสุนทรีย์ ศิลปะ เครื่องประดับ |
| Mars | การปลดปล่อยพลังงาน การยืนยันตัวตน การกระทำ การแข่งขัน อาวุธ ความร้อน |
| Jupiter | การขยายตัว ผลประโยชน์ ความเจริญเติบโต ความมั่งคั่ง โชคดี |
| Saturn | ระเบียบ โครงสร้าง ความมั่นคง วินัย ความรับผิดชอบ วัยชรา |
| Uranus | (จะกล่าวถึงในบทถัดไปพร้อมดาวสมมติทั้ง 8 ดวง) |

*หมายเหตุ: หนังสือมีคำหลักครบทั้ง 16 ดาว (รวม Uranus, Neptune, Pluto และดาวสมมติ 8 ดวง) แต่ตารางในเอกสาร Phase 1 และ Phase 3 ได้ครอบคลุมความหมายเชิงประยุกต์ของดาวเหล่านี้ผ่านคู่ดาว (planetary picture) ไว้แล้ว จึงไม่ทำซ้ำในเอกสารนี้*

**สำหรับ engine:** คำหลัก 4 มิตินี้ (Principle/Function/Expression/Manifestation) เหมาะเป็น field แยกในฐานข้อมูล เพื่อให้ synthesis layer เลือกใช้มิติที่ตรงกับคำถามของผู้ใช้ (เช่น ถามเรื่องอาชีพ → ดึง Manifestation, ถามเรื่องความรู้สึก → ดึง Expression)

## บทที่ 3: การคำนวณดวงชะตา (Calculation of the Horoscope)

บทนี้เป็นเนื้อหาเชิงเทคนิคเกี่ยวกับการคำนวณตำแหน่งดาวด้วยมือ (ก่อนยุคซอฟต์แวร์) ครอบคลุม:
- **Sidereal Time (ST)** และการแปลงเวลาสุริยะเป็นเวลาดาวฤกษ์
- **GMT Interval (INT)**, **Correction (COR)**, **Longitude-Time Equivalent (LTE)** — ค่าที่ใช้แปลงเวลาเกิดท้องถิ่นเป็นตำแหน่งดาวที่แม่นยำ
- สูตร **RAMC** (Right Ascension of the Midheaven) สำหรับคำนวณ M
- การคำนวณ **Ascendant (A)** ซึ่งต้องใช้ทั้งลองจิจูด ละติจูด และเวลา
- **Planetary Interpolation** — การประมาณตำแหน่งดาว ณ เวลาที่ต้องการจากค่าใน ephemeris (ตารางตำแหน่งดาวรายวัน)
- ตำแหน่งของดาวสมมติ (transneptunian planets) ต้องใช้ ephemeris เฉพาะทาง แยกจาก ephemeris ดาวเคราะห์ทั่วไป

**สำหรับ engine:** เนื้อหาบทนี้ส่วนใหญ่ถูกแทนที่ได้ด้วยไลบรารีดาราศาสตร์สมัยใหม่ (เช่น Swiss Ephemeris) ซึ่งคำนวณตำแหน่งดาวแม่นยำกว่าการคำนวณด้วยมือมาก — ประเด็นสำคัญที่ต้องเก็บไว้คือ **ต้องมี ephemeris ของดาวสมมติ 8 ดวงแยกต่างหาก** เพราะไม่ใช่ดาวเคราะห์จริงตามหลักดาราศาสตร์ (Swiss Ephemeris มีชุดข้อมูลสำหรับดาวเหล่านี้ในนามส่วนขยาย)

## บทที่ 4: เรือนโหราศาสตร์และ 360°-Dial

### ระบบเรือนแบบยูเรเนียน
ระบบยูเรเนียนใช้ **เรือนแบบ equal-house ที่อ้างอิงจาก M** ไม่ใช่ระบบ Placidus หรือ Koch ที่นิยมในโหราศาสตร์ตะวันตกทั่วไป — แต่ละราศีมีความสัมพันธ์เชิง "ต้นแบบ" (archetypal) กับเรือนหนึ่งๆ (เช่น Libra ↔ เรือนที่ 1 ในระบบยูเรเนียน)

### 360°-Dial (หน้าปัดวงกลม 360°)
เป็นเครื่องมือทางกายภาพ (แผ่นดิสก์หมุนได้) ที่ใช้:
1. บันทึกตำแหน่งดาวทั้งหมดรอบวงกลม โดยปกติวาง 0° Cancer ไว้บนสุด
2. หมุนหน้าปัดเพื่อตรวจดูว่าดาวใดตกในเรือนใด เมื่อเทียบกับจุดส่วนบุคคลแต่ละจุด (M, A, Sun, Moon, Node)

### แนวคิด Reflex Action (เรือนสะท้อนกลับ)
เรือนแต่ละเรือนมี "เรือนสะท้อน" (reflex house) อยู่ตรงข้ามกัน — ถ้าดาวตกในเรือนหนึ่งของแกน M เช่น เรือนที่ 11 ก็หมายความว่า M เองก็ตกอยู่ในเรือนที่ 2 ของดาวดวงนั้นเช่นกัน (11 กับ 2 เป็นคู่สะท้อนกัน) — การพิจารณาทั้งสองด้านของความสัมพันธ์นี้ช่วยให้การตีความสมบูรณ์ขึ้น

**สำหรับ engine:** ระบบเรือนของยูเรเนียนแตกต่างจากระบบเรือนทั่วไปที่ user คุ้นเคย (เช่น Placidus) จึงควรระบุให้ชัดในหน้า UI ว่าแอปใช้ระบบเรือนแบบยูเรเนียน ไม่ใช่ระบบเรือนดั้งเดิม เพื่อไม่ให้ผู้ใช้สับสนเมื่อเทียบกับแอปโหราศาสตร์ทั่วไป

## บทที่ 5: มุมสัมพันธ์ (Aspects)

### หลักการสังเคราะห์ดวงชะตา (Chart Synthesis)
เรือนบอกได้แค่ "บริบท" ที่ดาวแสดงอิทธิพล — แต่ไม่ครอบคลุมความสัมพันธ์เชิงพลวัตระหว่างดาว 22 ดวง หนังสือเน้นว่าการสังเคราะห์ (synthesis) ที่สมบูรณ์ต้องผสาน:
1. ดาวที่อยู่ในเรือนเดียวกัน (ทำงานร่วมกันแบบคอนจังชัน)
2. ดาวในเรือนสะท้อน (reflex house)
3. Aspect ระหว่างดาว (บทนี้)
4. Planetary Pictures (บทที่ VI-VIII ตามเอกสาร Phase 2)

### ตัวชี้วัดสำคัญที่เชื่อมโยงกับ Phase 2
บทนี้เป็นพื้นฐานก่อนเข้าสู่บทที่ VI-VIII (Planetary Pictures) ซึ่งเอกสาร Phase 2 ได้ครอบคลุมรายละเอียดตรรกะการคำนวณ hard/soft aspect และเหตุผลที่ระบบยูเรเนียนไม่แบ่ง aspect เป็น "ดี/ไม่ดี" ไว้แล้ว — ให้อ้างอิงเอกสารนั้นประกอบ
