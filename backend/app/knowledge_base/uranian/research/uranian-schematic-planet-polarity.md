# แผนภาพ "Schematic Combinations of the Planets" — สรุปวิจัย (ที่มาไม่ยืนยัน)

> ถอดความจากภาพแผนภาพเดี่ยว (ไม่มีเนื้อหาข้อความประกอบ) ที่ผู้ใช้ส่งมา — ไม่มีหน้าปก ผู้แต่ง หรือชื่อ
> หนังสือกำกับ ลักษณะเป็นเอกสารพิมพ์ดีดยุคเก่า (typewriter-style) สอดคล้องกับเอกสารสาย Witte/Hamburg
> School หรือแผ่นพับภาษาอังกฤษยุคแรกๆ ของระบบยูเรเนียน แต่**ไม่สามารถยืนยันแหล่งที่มาที่แน่นอนได้**จาก
> ภาพเพียงอย่างเดียว — ถือเป็นข้อมูลชั้นรอง (suggestive) ที่ควรรอการยืนยันไขว้จากแหล่งอื่นก่อนนำไปใช้อ้างอิง
> อย่างเป็นทางการ ไม่เหมือนเอกสารอื่นในโฟลเดอร์นี้ที่ระบุที่มาชัดเจน

**ข้อจำกัดในการอ่าน:** สัญลักษณ์บางจุดในภาพ (โดยเฉพาะตัวอักษร e/i ที่ปรากฏใกล้ Mercury/Venus) อ่านได้
กำกวม เทียบกับ legend ท้ายภาพ (e=external, i=internal, d=down/below, u=up/above) แล้วยังไม่แน่ใจว่า
หมายถึงอะไรกันแน่ — ไม่ขอตีความยืนยันจุดนี้

## 1. โครงสร้างที่เห็น

แผนภาพจัดวางปัจจัย **16 ตัว** เรียงเป็นแถวเดียว: ดาวเคราะห์คลาสสิก 8 ดวง (Mercury ถึง Pluto ไม่รวม
ดวงอาทิตย์/จันทร์) ตามด้วยดาวเสริมทั้ง 8 ดวง (Cupido ถึง Poseidon) — **ตรงกับกลุ่ม "16 ดาวโตด" ที่
เอกสาร `uranian-charun-pikul-reading-process.md` ระบุไว้แล้วเป๊ะ** (นับ C(16,2)=120 ศูนย์รังสีที่นั่น) เป็น
การยืนยันไขว้อีกครั้งว่ากลุ่ม "16 ปัจจัยที่ไม่ใช่จุดเจ้าชะตา" เป็นหน่วยจัดกลุ่มมาตรฐานจริงของระบบนี้

จากปัจจัยทั้ง 16 ตัว มีเส้นประลากลงมาสร้าง "แถบธีม" (thematic band) ที่คาบเกี่ยวกันเป็นชั้นๆ ไล่จากบนลง
ล่าง:

- **หัวเรื่องบนสุด ("Day-side")**: กรอบธีมแง่บวก/สร้างสรรค์ — การก่อร่างสร้างตัว การสืบทอด การฟื้นฟู
- **แถบกลางบน**: ธีมย่อยเช่น การปฏิสนธิ/เติบโต, การจัดระเบียบ/ขยายตัว — คาบเกี่ยวกับดาวกลุ่มต้นๆ ถึงกลาง
  แถว
- **แถบเดี่ยวต่อดาว**: คำเดี่ยวกำกับดาว/กลุ่มดาวเฉพาะจุด — เช่น "สสาร/วัตถุ" ที่ Mercury, "ชีวิต" แถว
  Mars/Jupiter, "เวลา" คาบเกี่ยว Pluto กับ Cupido, "ปริภูมิ/พื้นที่" คาบเกี่ยว Zeus-Kronos-Apollon,
  "พลัง/กำลัง" ที่ Vulcanus-Poseidon
- **แถวจุดอ้างอิงส่วนตัว**: มีป้าย **SUN**, **MERIDIAN**, **ASCENDANT** วางอยู่ตรงตำแหน่งเฉพาะใน
  สเปกตรัม (Sun อยู่แถว Venus/Mars, Meridian อยู่แถว Neptune/Pluto/Cupido, Ascendant อยู่แถว
  Zeus/Kronos/Apollon) — เหมือนกำลังบอกว่าจุดส่วนตัวแต่ละจุดมี "โทน" ธีมที่ใกล้เคียงกับดาวกลุ่มไหนในสเปกตรัม
  นี้เป็นพิเศษ
- **แถบล่างไล่ลงเรื่อยๆ**: ธีมแง่ลบ/เสื่อมสลายมากขึ้นเรื่อยๆ ตามลำดับ (ความเน่าเปื่อย → ซากศพ/ขยะ →
  หมอก/อากาศ → น้ำแข็ง/ดิน → เรื่องร้าย/อาชญากรรม → การเยาะเย้ยถากถาง) กว้างขึ้นเรื่อยๆ จนถึงแถบกว้างสุด
  ที่คาบเกี่ยวเกือบทุกดาวพร้อมกัน
- **หัวเรื่องล่างสุด ("Night-side")**: กรอบธีมแง่ลบ/ทำลาย — การรื้อถอน การแยกส่วน

## 2. สิ่งที่แผนภาพนี้เพิ่มเข้ามาจริง — โครงสร้าง "ขั้วบวก-ขั้วลบ" ต่อปัจจัย

`points.yaml`/`factors.yaml` ในปัจจุบันเก็บ **`meaning_core` เดียว** ต่อปัจจัยหนึ่งตัว (ดูโครงสร้างที่
README อธิบายไว้) ไม่มี field แยกสำหรับ "ความหมายเชิงบวก/สร้างสรรค์" กับ "ความหมายเชิงลบ/เสื่อมสลาย"
ของปัจจัยเดียวกัน — แผนภาพนี้ชี้ว่าในทางปฏิบัติของสำนักนี้ ดาวแต่ละดวงมีทั้งสองขั้วเสมอ (คล้ายกับที่ไพ่ทาโรต์
มีความหมายตั้งตรง/กลับหัว) ขึ้นอยู่กับบริบทของ picture ที่พบ — เป็นมิติที่ **ยังไม่มีอยู่ใน schema ปัจจุบัน
ของ KB นี้เลย**

**ข้อควรระวังก่อนนำไปใช้จริง:** เนื่องจากไม่ยืนยันที่มาของแผนภาพได้ และมีแค่ภาพเดียวไม่มีคำอธิบายประกอบ
ควรถือเป็นข้อมูล**เชิงตั้งสมมติฐาน** ไว้ก่อน ยังไม่ควรนำไปสร้าง field ใหม่ใน `points.yaml`/`factors.yaml`
จนกว่าจะมีแหล่งข้อมูลที่ยืนยันที่มาชัดเจนกว่านี้มาสนับสนุน (เช่น ถ้าผู้ใช้ทราบว่าแผนภาพนี้มาจากหนังสือเล่ม
ไหน จะช่วยยืนยันความน่าเชื่อถือและอาจมีเนื้อหาข้อความประกอบที่อธิบายละเอียดกว่านี้)

## 3. สรุปสิ่งที่ actionable

| หัวข้อ | สถานะ | ควรทำอะไรต่อ |
|---|---|---|
| กลุ่ม "16 ดาวโตด" | ยืนยันไขว้กับ Charun Pikul แล้ว | ไม่ต้องแก้ — เป็นการยืนยันเพิ่มเติมเท่านั้น |
| โครงสร้างขั้วบวก-ลบต่อปัจจัย (Day-side/Night-side) | แนวคิดใหม่ ยังไม่มีใน schema | **ไม่ implement ตอนนี้** — รอยืนยันที่มาหรือแหล่งข้อมูลสนับสนุนเพิ่มก่อน |
| ตำแหน่ง Sun/Meridian/Ascendant บนสเปกตรัม | เทคนิคที่ไม่เคยเห็นในเอกสารอื่นของ KB นี้ | บันทึกไว้เฉยๆ ยังไม่มีข้อมูลพอจะตีความว่าใช้งานจริงอย่างไร |
| ที่มาของแผนภาพ | ไม่ยืนยัน | ถ้าผู้ใช้ทราบชื่อหนังสือ/ผู้แต่ง ควรระบุเพิ่มเพื่อยกระดับความน่าเชื่อถือของเอกสารนี้ |
