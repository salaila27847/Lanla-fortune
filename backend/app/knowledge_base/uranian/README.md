# Uranian knowledge base

## โครงสร้าง

```
points.yaml   ← 8 ดาวเสริม (Cupido, Hades, Zeus, Kronos, Apollon, Admetos,
                 Vulkanus, Poseidon) — id, swe_id (40-47), name_th, keywords,
                 meaning_core (ความหมายหลักของดาวดวงนั้น ไม่ขึ้นกับราศี)
signs.yaml    ← 12 ราศี — id, name_th, start_degree, modifier (วลีปรับสีสัน
                 การแสดงออกของดาวเสริมเมื่ออยู่ในราศีนั้น)
```

`app/modules/uranian/engine.py` คำนวณตำแหน่งจริงด้วย `pyswisseph` (อีเฟเมอริส Moshier
ในตัว ไม่ต้องใช้ไฟล์ข้อมูลเสริมหรืออินเทอร์เน็ต):

1. แปลงวัน/เวลา/เขตเวลาเกิดเป็น Julian Day (UT) ด้วย `zoneinfo` — ถ้าไม่ทราบเวลาเกิด
   ใช้เที่ยงวันเป็นค่าประมาณ และลดค่า `confidence` ลง พร้อมแจ้งข้อจำกัดใน findings
2. คำนวณตำแหน่งดาวเสริมทั้ง 8 ดวง จับคู่กับราศีและองศาที่อยู่ ประกอบความหมายจาก
   `points.yaml` + `signs.yaml`
3. คำนวณ "midpoint หลัก" — จุดกึ่งกลางระหว่างจุดส่วนตัว (ดวงอาทิตย์, ดวงจันทร์,
   และลัคนา/เมอริเดียนถ้าทราบเวลาเกิด) แล้วตรวจว่าดาวเสริมดวงใดตกลงบนจุดนั้นบน
   90° dial (mod 90, orb 1.5°) — ถ้าตรง จะสร้าง Finding แยกที่มีน้ำหนัก (weight) สูงกว่า
   placement ปกติ เพราะเป็นสัญญาณที่เฉพาะเจาะจงกว่า

ไม่มี hardcode เนื้อหาความหมายในโค้ด engine ทั้งหมดโหลดจากไฟล์ YAML ข้างต้น
