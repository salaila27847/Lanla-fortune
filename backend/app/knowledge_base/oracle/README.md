# Oracle knowledge base

ผู้ใช้ยืนยันแล้ว (2026-08-12): ชุดไพ่หลักของแอปเป็นชุดที่สร้างขึ้นเอง (ไม่ใช้สำนักสำเร็จรูป)
ผสาน 3 ธีม — เทวดา & นางฟ้าผู้พิทักษ์, สัตว์นำทางแบบไทย, ดอกไม้แห่งจิตวิญญาณ — รวม 60 ใบ
แต่สถาปัตยกรรมรองรับให้ผู้ใช้เลือกสลับไปใช้ deck อื่นได้ในแอปด้วย

## โครงสร้าง

```
decks/
  lanla_original/       ← deck หลักของแอป (default)
    deck.yaml           ← metadata: id, ชื่อ, คำอธิบาย, รายชื่อหมวดหมู่
    guardian.yaml        ← 20 ใบ: เทวดา & นางฟ้าผู้พิทักษ์
    animal.yaml           ← 20 ใบ: สัตว์นำทางแบบไทย
    flower.yaml            ← 20 ใบ: ดอกไม้แห่งจิตวิญญาณ
  <deck อื่นๆ ในอนาคต>/   ← เพิ่ม folder ใหม่ตาม pattern เดียวกัน แล้วเรียกผ่าน draw(deck="...")
```

การ์ดแต่ละใบมี `id`, `name_th`, `keywords`, `meaning` — engine (`app/modules/oracle/engine.py`)
โหลดไฟล์เหล่านี้ตรงและสุ่มจั่ว ไม่มี hardcode เนื้อหาการ์ดในโค้ด
